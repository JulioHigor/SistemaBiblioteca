# 📚 Sistema Biblioteca

Projeto desenvolvido como parte dos meus estudos em Python, com o objetivo de praticar os fundamentos da linguagem e o desenvolvimento de um sistema de gerenciamento de livros utilizando SQLite para persistência dos dados.

O sistema implementa as operações básicas de um CRUD (Create, Read, Update e Delete), permitindo cadastrar, listar, buscar, editar e remover livros diretamente pelo terminal.

---

## 🚀 Funcionalidades

- Cadastro de livros
- Listagem de livros
- Busca por título
- Busca por ID
- Edição de livros
- Remoção de livros
- Validação de entradas do usuário
- Persistência dos dados utilizando SQLite

---

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

2. Acesse a pasta do projeto:

```bash
cd SistemaBiblioteca
```

3. Execute o programa:

```bash
python main.py
```
